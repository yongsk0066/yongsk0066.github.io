もう3日目になる。韓国では日曜日が終わったが、こちらはまだ日曜日が始まったばかりの午前10時頃だ。
毎晩寝る前に記録を残そうと思っていたが、
時差ボケに悩まされながら撮影したものを整理し、緊張が解けてシャワーを浴びたら眠ってしまった。

マウンテンビューに到着して、昨日はサンフランシスコに一泊し、帰り道にパロアルトで降りた。

サンフランシスコも綺麗ではあったが、やはり人気のない道を一人で歩いていると、緊張する瞬間があった。
一方、南のほうは確かに郊外の雰囲気で清潔感があり、安全な感じがして安心する。（それに、思ったより韓国人をよく見かける。）

9時頃にCaltrainを降りて、軽く腹ごしらえをしてから、近くにブルーボトルがあったので寄ってみた。

コーヒーの味の違いがよく分からないので、テヘランロ（ソウルのオフィス街）ではあまり飲まなかったが、ここで飲んだからといって魔法のように変わるわけでもなく、
テヘランロで飲んでいた感覚が重なって不思議な気分だった。

横断歩道を渡ってポスコタワーに入らなきゃいけないような...そんな気持ちになる。

写真もスマートフォンに移すついでに...ここでもコミットを一つ残す機会を掴んでノートパソコンを開いた。

MacからGalaxyに移すとき、AndroidのFile Shareを使っていたが、いつからか動かなくなった。
それでクラウドにアップロードしてからダウンロードする方法で移していたが、ホテルのWi-Fiでアップロード・ダウンロードするのが重すぎて、方法を探しているうちに
adbでpushする機能を発見した。

```shell
❯ for file in sfo_2*.mp4; do adb push --sync "$file" /sdcard/download/sanfran2; done
sfo_2.mp4: 0 files pushed, 1 skipped.
sfo_2_00300048.mp4: 1 file pushed, 0...5.3 MB/s (197287814 bytes in 5.323s
sfo_2_00300432.mp4: 0 files pushed, 1 skipped.
sfo_2_00300552.mp4: 0 files pushed, 1 skipped.
sfo_2_00300960.mp4: 0 files pushed, 1 skipped.
sfo_2_00301440.mp4: 0 files pushed, 1 skipped.
```

こんな感じで`adb push --sync`を使って転送できた。`--sync`は変更の有無をチェックして、変更がなければスキップしてくれる。
転送中に途中で切れたことで知ったオプションだ。

https://developer.android.com/tools/adb?hl=ko#copyfiles


7ドル＋アルファ（クッキー1枚分）のコミットを一つ残して、そろそろ戻ろう。

もうすぐ韓国は月曜日なので、会社のランチボットにランチメニューを更新しなければならないのが心配だ。
一週間ほど更新を逃したことはまだないので、ランチボットのリテンションが下がるんじゃないかと心配だ...会社のノートパソコンを持ってくればよかった...

データ残量が少なくなったので、そろそろ退散する時間になった。
